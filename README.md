# Nexo

A no-magic, server-first full-stack framework for [Bun](https://bun.sh).

> **Status:** early development. Nothing is usable yet.

## Principles

- **No magic.** Every behavior can be traced to the line of code that causes it.
- **Zero runtime dependencies.** Routing, rendering, reactivity and motion are built from scratch on web standards.
- **Server-first.** HTML is rendered on the server; each route explicitly declares how.
- **Low floor, high ceiling.** Easy to start, with room to grow as far as you need.
